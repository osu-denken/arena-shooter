# アリーナ・シューター

大阪産業大学 電子計算研究部の部員が制作した、ブラウザで遊べる三人称/一人称アクションゲームです。
銃と剣を切り替えながら、アリーナに現れる敵をすべて倒します(全5ステージ + ラスボス)。

- **遊ぶ**: https://osu-denken.net/arena-shooter/ (PCのブラウザ推奨。スマホ・タブレット非対応)
- **操作**: WASD 移動 / Shift ダッシュ / E ジェットパック / V 視点切替 / 1 銃・2 剣 / 左クリック 攻撃 / 右クリック ズーム(スナイパー) / R リロード / M ミュート / Esc メニュー(一時停止・音量・リタイア)
- **コントローラー**: PS4 などのゲームパッドにも対応(USB / Bluetooth でつないでボタンを1回押す)。左スティック 移動 / 右スティック 視点 / R2・○ 攻撃 / L2 ズーム / × ジェット / □ リロード / △・R1 持ち替え / OPTIONS メニュー

このリポジトリには、Unity(2022.3, WebGL)でビルドした**公開用ファイルだけ**が入っています。
ゲームのソースやアセットは含まれていません。
